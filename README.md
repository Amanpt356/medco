# Medco 💊

A MERN stack medical store management system for managing medicine inventory, tracking manufacturing and expiry dates, and receiving alerts for medicines nearing expiry.

Features

User signup and login

Add, edit, delete, and search medicines

Add medicine details manually or scan barcodes

Track manufacturing and expiry dates

Expiry alerts for medicines nearing expiry

Identify expired medicines

Dashboard with inventory statistics

Tech Stack

Frontend: React.js

Backend: Node.js, Express.js

Database: MongoDB

Authentication: JWT, bcrypt

Styling: CSS / Tailwind CSS

Scanning: Barcode Scanner / OCR
